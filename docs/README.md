# docs

Contributor docs. Start with [AGENTS.md](../AGENTS.md) at the repository root.

- [overview.md](overview.md): the areas, how they talk, where data lives, how it is built and shipped.
- [decisions.md](decisions.md): decisions a change must not undo.
- [areas/](areas/): one doc per area: main files, what it talks to, what must stay true, what is easy to break, how to check a change.
- [worktrees.md](worktrees.md): many worktrees on one host, stands, slots, ports, host requirements.
- [atlas.md](atlas.md): the base atlas: design, tasks with done criteria, measurements.
- [circuits-format.md](circuits-format.md): the circuit snapshot format between the Lua reader and the Python simulator.
- [research/](research/): surveys of upstream projects the skills were ported from or inspired by.
- `agent-readiness.md`: the last readiness assessment of this repository.
